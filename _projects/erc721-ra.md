A unique, Solidity-based smart contract built for the Code Rebels NFT collection. The contract enhances security and user trust by verifying Twitter accounts before an NFT can be minted, and ensures fairness by limiting each wallet to a single mint. It also introduces a built-in marketplace feature that lets users place bids and asks for NFTs directly within the platform.
